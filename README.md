# TravelSphere-Analytics
📌 Project Overview
- Developed an interactive Tableau dashboard to analyze hotel review data and provide business insights for TravelSphere. The dashboard helps stakeholders understand customer satisfaction, hotel performance, reviewer demographics and seasonal trends.

Business Problem
- TravelSphere needed an interactive dashboard to better understand customer feedback and hotel performance across different cities and seasons. This project focuses on transforming raw hotel review data into actionable business insights through interactive visualizations.

🎯 Project Objectives
- Analyze hotel review data.
- Identify customer satisfaction trends.
- Visualize hotel performance.
- Support business decision-making through interactive dashboards.

🛠 Technologies Used
- Tableau Prep
- Tableau Desktop

- 🧹 Data Cleaning
- 📊 Data Visualization
- 🎨 Dashboard Design
- 🗄️ SQL Query
